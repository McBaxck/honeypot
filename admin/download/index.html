HolyPot Admin

L'interface d'administration du honeypot s'utilise en application desktop.

Télécharger pour macOS (Apple Silicon)

Application non signée : à l'ouverture, macOS Gatekeeper la bloquera ("non identifié"). Clic droit → Ouvrir, ou Préférences Système → Sécurité → Ouvrir tout de même. L'app se connecte à l'API HolyPot sur localhost:5050.
